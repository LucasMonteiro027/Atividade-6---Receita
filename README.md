# Atividade-6---Receita

Um site de receitas culinárias, contendo uma home page com imagens de 3 receitas de sua escolha. Usando as seguintes tecnologias:
* HTML: Estruturação das páginas e conteúdo.
* CSS: Estilização com foco em contraste e legibilidade.
* JavaScript: Lógica de interface, incluindo sistema de busca em tempo real e checklist interativo.

 Funcionalidades
* Busca Dinâmica: Filtro instantâneo das receitas na página inicial sem recarregar a página.
* Checklist de Ingredientes: Sistema interativo que permite ao usuário "riscar" os ingredientes enquanto cozinha.
* Navegação: Layout intuitivo com cards interativos e botões de retorno rápido.
